# DiGiTAL POiNT SK

A student-focused portal for online form updates, admission notices, exam dates, scholarships, result updates, and university news.

## Tech Stack

- **Framework:** TanStack Start (React 19, TanStack Router v1)
- **Build:** Vite 7
- **Styling:** Tailwind CSS 4
- **Language:** TypeScript 5.7 (strict mode)
- **Deployment:** Netlify

## Running Locally

```bash
npm install
npm run dev
```

The development server starts at `http://localhost:3000` (or port 8888 via Netlify CLI).

To run with full Netlify feature emulation:

```bash
netlify dev
```

## Building for Production

```bash
npm run build
```
